# **App Name**: Keystone Redactor

## Core Features:

- Real-time PII Redaction Demo: An interactive terminal-like UI tool that animates the local AI redaction process, demonstrating how sensitive text is transformed into anonymized placeholders.
- Value Proposition Showcase: Prominently display key messaging in a hero section, emphasizing zero-knowledge, local AI privacy, and automated restoration.
- Problem vs. Solution Analysis: A clear, side-by-side comparison outlining the risks of unredacted data versus the secure benefits of Keystone.
- Deep-Tech Feature Details: Engaging display of critical technical features including local SQLite persistence, OWASP compliance, and n8n automation, presented in a bento-box card layout.
- Compliance & Trust Badges: A dedicated, full-width section to build user trust by highlighting adherence to industry security standards (e.g., SOC2, HIPAA, PCI-DSS).
- User Navigation & Call to Actions: A minimalist, responsive navigation bar with clear links to main sections and primary/secondary calls to action for download and GitHub access.
- Local Persistent Storage: Securely manage application configuration, API keys, and audit logs entirely offline using a local SQLite database.

## Style Guidelines:

- Primary interactive elements: A sophisticated, muted 'Safety' Emerald Green (#10B981) for buttons, highlights, and success indicators, chosen to convey security and trust against a dark background.
- Main background: Deep Charcoal/Almost Black (#0B0B0B), setting a high-contrast, professional, and brutalist tone.
- Surface and card backgrounds: Dark Slate (#1A1A1A), utilized for distinct UI components, accented with subtle 1px borders (#333333).
- Heading text: High contrast stark white (#F3F4F6) for maximum readability and visual impact on dark backgrounds.
- Body text: Muted gray (#9CA3AF) to provide softer contrast and readability for longer content blocks.
- General text and headings: 'Inter' (sans-serif) for its crisp, modern, and serious appeal, aligning with a high-trust developer aesthetic. Note: currently only Google Fonts are supported.
- Monospaced text (for displaying API keys, logs, and technical specifications): 'Source Code Pro' (monospace) to enhance the technical and precise nature of such content.
- Crisp, minimalist vector icons from Lucide React, ensuring visual clarity and consistency within the technical and high-trust interface.
- A brutalist-developer style layout featuring strong grid structures (e.g., bento box for features), 2-column comparison grids, and distinct full-width banners for key information, focusing on density and immediate clarity.
- Smooth, highly engineered micro-interactions powered by Framer Motion, including subtle fade-ins, border-glows on hover for interactive elements, and staggered content reveals, strictly avoiding any bouncy or overly playful effects.
